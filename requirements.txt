# What the program needs beyond the standard library. It installs both by
# itself on first use; this file is for anyone who would rather do it
# beforehand, or in a virtual environment.
#
#   python3 -m pip install -r requirements.txt
#
# ffmpeg and ffprobe are not Python packages and are not in here. They have
# to be in the search path or next to the script: brew install ffmpeg on a
# Mac, the package manager on Linux, ffmpeg.org on Windows.
numpy
PySide6
# The list of trusted authorities an https connection is checked
# against. Python brings none of its own, and without it the check
# for new versions and the speaker model both fail with
# CERTIFICATE_VERIFY_FAILED.
certifi
# Speech recognition. Large, and pulled in at once because the
# program uses it as soon as a transcript is wanted.
faster-whisper
# The speaker separation. Cutting by who is speaking is what this
# program is for, so it is not an extra -- and it is the largest thing
# here by far: with torch and torchvision some 828 MB, measured
# 4.9.2026. torchvision is named although pyannote pulls it in anyway,
# because torchmetrics imports its image half eagerly and without it
# "import pyannote.audio" dies at a name it never uses.
pyannote.audio
torchvision
